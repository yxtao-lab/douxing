## 1. 主标语（Primary）

| 语言 | 文案 |
|------|------|
| **zh-CN** | **你负责游玩，其他的交给我** |
| **en-US** | **You explore — I'll handle the rest.** |

### 1.1 含义拆解

| 半句 | 用户侧 | 产品侧（兜行） |
|------|--------|----------------|
| **你负责游玩** | 轻松出行、专注体验与记录 | 降低决策与执行焦虑 |
| **其他的交给我** | 不用操心行程细节 | AI 规划、住行编排、相册整理、打卡成就等 **幕后能力** |

与产品链路对应：规划（C）→ 住行（H9）→ 行中（H7/H8，远期）→ 相册（J 线）→ 手帐分享（H2）。

### 1.2 使用原则

- **对外主 Slogan** 以本节 zh-CN / en-US 为准；勿擅自改「游玩」为「旅行/旅游」 unless  A/B 测试立项。
- 全站上线前须走 **G9 i18n**：键名建议 `brand.slogan.primary`（shared 或 mobile/web 端专属 locales）。
- 海报、闪屏等 **空间有限** 时可只用前半句或缩短版（见 §3）。
- 禁止与「MVP」「体验账号」等内部用语同屏出现。

## 4. 视觉与排版建议

- **主标语**：Hero、海报主标题 — 字重 600～700；zh-CN 可 28～40rpx（移动）/ 24～32px（Web）。
- **「其他的交给我」** 可用 `--dx-primary` 或 `--dx-accent` 高亮后半句（可选）。
- 与 [品牌视觉规范 §6 Hero](./品牌视觉规范.md#6-渐变与-hero) 渐变底搭配；保证 `--dx-text-inverse` 对比度。
- 手帐海报底栏：主标语 ≤ 一行，字号小于路线名，避免抢主信息。
