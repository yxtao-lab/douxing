## VoiceTextComposer · 语音文字输入框

### 功能

统一的聊天式底部输入组件，支持：

- **文字模式（默认）**：多行输入、发送按钮、可切换语音
- **语音模式**：按住说话、松开发送、上滑取消
- **录音态 UI**：蓝色胶囊按钮 + 竖条声波动画；取消时变红
- **跨端语音**：H5（Web Speech API）、微信小程序 / App（录音上传 + 服务端 ASR）

业务侧只需处理 `@send` 返回的文本，无需关心录音、识别、模式切换等细节。

### 封装方式

| 层级 | 说明 |
|------|------|
| **组件** | UI、模式切换、按住/松开手势、上滑取消、波形动画 |
| **工具** | `@/utils/speech-to-text.ts` 按平台条件编译，统一 `startSpeechToText` / `stopSpeechToText` |
| **录音** | `speech-to-text.recorder-upload.ts` 封装 `RecorderManager`，松手后上传音频 |
| **接口** | `@/api/speech.ts` → 后端 `POST /api/speech/transcribe` |

设计要点：

- 使用 **`v-model`** 绑定输入内容；发送逻辑由父组件通过 **`@send`** 处理
- 录音 session、按住状态、异步启动竞态均在组件内部管理
- 通过 **`defineExpose({ clear })`** 暴露清空方法，供发送成功后重置输入框
- 样式自包含（`scoped`），不依赖页面级 CSS 变量

| 事件 |  payload | 说明 |
|------|----------|------|
| `update:modelValue` | `string` | 输入内容变化（`v-model`） |
| `send` | `string` | 点击发送，或语音识别完成后触发，参数为待发送文本 |

|------|------|
| `clear()` | 清空内容并重置 `textarea`（发送成功后调用） |

### 基本用法

```vue
<template>
  <VoiceTextComposer
    ref="composerRef"
    v-model="inputText"
    placeholder="描述你的需求..."
    :disabled="loading"
    :loading="loading"
    @send="handleSend"
  />
</template>

<script setup lang="ts">
import { ref } from 'vue';
import VoiceTextComposer from '@/components/voice-text-composer/VoiceTextComposer.vue';

const composerRef = ref<InstanceType<typeof VoiceTextComposer> | null>(null);
const inputText = ref('');
const loading = ref(false);

async function handleSend(text: string) {
  const content = text.trim();
  if (!content) return;

  loading.value = true;
  composerRef.value?.clear();

  try {
    await submitMessage(content);
  } catch {
    inputText.value = content; // 失败时恢复输入
  } finally {
    loading.value = false;
  }
}
</script>
```

### 默认语音模式

```vue
<VoiceTextComposer
  v-model="inputText"
  default-mode="voice"
  @send="handleSend"
/>
```

### 交互说明

1. **文字模式**：输入 → 点「发送」或键盘确认 → 触发 `send`
2. **语音模式**：按住 → 录音 + 波形 → 松开 → 识别 → 自动 `send`
3. **上滑取消**：录音过程中上滑超过阈值 → 按钮变红 → 松开放弃识别与发送
