# 旅行日记博客（K-A 线）

> **录入日期**：2026-06-10  
> **定稿日期**：2026-06-10  
> **定位**：个人用户将 **一次旅程** 整理为可公开的 **旅行日记网页**；访客 **无需登录** 即可通过分享链接阅读；**仅作者显式开放的内容块** 对访客可见。支持 **多模板、多主题、可插拔内容元素**。  
> **路线图编号**：**K-A0～K-A5**（见 [ROADMAP.md § K-A](./ROADMAP.md#阶段-ka旅行日记博客2026-06-10-定稿)）  
> **当前状态**：**方案定稿**（K-A0）；代码未启动  

**与 K-B（品牌博客）区分**：K-B 为运营/技术 Markdown 站点（`blog.yxtao.site` 等）；**K-A 为 C 端用户产品**，挂在模块 A，复用路线、相册、打卡、手帐能力。

---

## 1. 产品目标

| 用户痛点 | 兜行解法 |
|----------|----------|
| 旅行回忆散落在路线、相册、打卡里，难以「讲故事」 | 从 **路线 + 旅程相册 + 打卡** 一键生成日记草稿，按天/POI 叙事 |
| 想分享给亲友，但不想暴露全部隐私 | **块级可见性**：某天、某段文字、某组照片可单独公开或隐藏 |
| 静态照片墙不够好看 | **多模板 Web 渲染**（分列行程、螺旋日记、导览图等），主题色/底纹可定制 |
| 分享页要登录才能看 | 公开 API + H5/PC **只读页**，与 D5/J5 分享链路一致，**无需 JWT** |
| 只有 PNG 手帐图，无法在网页里翻页阅读 | 在 H2 海报之外增加 **可浏览的旅行博客页**；海报仍可「生成分享图」导出 |

**一句话**：**路线是骨架，相册是画面，日记是叙事；开放什么，访客就看见什么。**

## 3. 用户故事与场景

### 3.1 作者（登录用户）

1. 结束一趟旅行后，在 **路线详情** 或 **我的相册** 点击「生成旅行日记」。
2. 系统从路线天/POI、相册分组、打卡记录 **预填内容块**（草稿态，默认全部 `private`）。
3. 作者编辑标题、选 **模板**（如 `timeline-columns` / `diary-page`）、选 **主题**（forest / ocean / magazine / minimal）。
4. 逐块设置 **是否公开**：例如隐藏酒店地址、隐藏同行人照片，只公开景点与心得。
5. 预览 → **发布** → 获得分享链接（`shareToken`）；可复制、生成小程序卡片、导出 PNG 海报（H2）。

### 3.2 访客（未登录）

1. 打开分享链接（H5 / PC / 小程序 webview）。
2. 看到作者选定的模板与主题下的 **仅公开块**；无登录入口强制打断阅读。
3. 底部品牌区可引流下载兜行 App（可选 CTA）。

### 3.3 个人主页（K-A4）

- 用户资料开启 `profileBlogEnabled` 后，公开 **`published`** 状态的日记列表。
- URL：`/@{handle}` 或 `/u/{userId}/journals`（MVP 后可上 slug）。

## 4. 可见性与隐私模型

### 4.1 发布状态（整篇）

| 值 | 说明 | 访客可见 |
|----|------|----------|
| `draft` | 草稿，未发布 | 否 |
| `published` | 已发布；配合 `shareToken` 或 slug 访问 | 是（仅 public 块） |
| `unlisted` | 不进入个人公开列表，但 **持链接者可读** | 是（仅 public 块） |

### 4.2 块级可见性

每个 `journal_block` 含 `visibility`：

| 值 | 说明 |
|----|------|
| `public` | 公开 API 返回并渲染 |
| `private` | 作者端可见；公开 API **不返回**（非 null 占位，直接省略） |

**服务端强制**：`GET /api/share/journals/:token` 在 SQL/序列化层过滤 `visibility != public`；禁止通过 query 参数窥探私有块。

### 4.3 与现有分享字段对照

| 能力 | 现有字段 | K-A 字段 |
|------|----------|----------|
| 路线广场 | `travel_routes.isPublic` | 日记 **独立**；远期可选 `journal.showInPlaza` |
| 相册链接 | `journey_albums.shareEnabled` + `shareToken` | `travel_journals.shareToken` + `publishStatus` |
| 海报 QR | 已发布路线即可（不要求广场公开） | 已 `published` 日记即可生成 QR |

### 4.4 合规与审核（上线前）

- 公开块中的用户文字、照片走 **腾讯云内容审核**（与 J 线/H10 共用策略）。
- 未审核通过：`publishStatus` 保持 `draft`，API 返回 `ApiMessageKey.JOURNAL_MODERATION_PENDING`。
- MVP 开发环境可跳过审核，生产必须开启。

## 5. 内容块类型（Journal Block）

块是有序的 JSON 文档片段，存储于 `journal_blocks.payload`，由模板声明 **支持哪些 block type**。

### 5.1 MVP 块类型（K-A1～K-A2）

| type | 说明 | 数据来源 |
|------|------|----------|
| `cover` | 封面 Hero：标题、副标题、封面图、天数、城市 | 路线 + 相册封面 |
| `day-header` | 第 N 天标题、日期、主题色 | `route_detail.days[i]` |
| `poi-section` | POI 名、说明、时间、标签、缩略图 | 行程 + 景点封面 |
| `text` | 用户心得（富文本 MVP 用 markdown 子集） | 用户输入 |
| `photo-grid` | 照片网格（1～9 张） | `travel_photos` |
| `photo-strip` | 横向照片条（diary-page 风） | `travel_photos` |
| `map-footprint` | 当日或全程足迹简图 | `map-path` + `check_ins` |
| `brand-footer` | 兜行品牌 + QR + CTA | 系统生成 |

### 5.2 二期块类型（K-A5）

| type | 说明 |
|------|------|
| `transit-card` | 交通段卡片（H9 enrich） |
| `tips-list` | 贴士列表 |
| `quote` | 引用/金句 |
| `stats-row` | 天数、城市数、打卡数、照片数 |
| `same-params-collage` | 同 EXIF 参数拼图（J5+） |
| `checkin-badge` | 打卡成就/徽章展示 |

### 5.3 从旅程生成草稿（K-A3）

算法概要：

1. 若存在 `route_id`：按 `days[]` 顺序生成 `day-header` + 每日 `poi-section`。
2. 若存在 `album_id`：按 `day_index` / `poi_name` 挂载 `photo-grid` 或 `photo-strip`（每 POI 最多 N 张，可配置）。
3. 若有打卡：在对应 POI 下追加 `checkin-badge` 或地图点。
4. 插入 `cover`、`brand-footer`；全文块默认 `visibility: private`，由作者批量改为 `public`。

### 6.3 主题（K-A2 轻量定制，对齐 H2-a+）

| themeId | 风格 | 说明 |
|---------|------|------|
| `classic` | 米黄手帐纸 | 默认；对齐 H2 主卡 |

## 8. API 概要（规划）

### 8.1 作者 API（需 JWT）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/journals` | 我的日记列表 |
| POST | `/api/journals` | 创建；body 可含 `routeId` / `albumId` 触发草稿生成 |
| GET | `/api/journals/:id` | 详情含 **全部块**（含 private） |
| PATCH | `/api/journals/:id` | 改标题、模板、主题、publishStatus |
| PUT | `/api/journals/:id/blocks` | 批量更新块顺序与 payload |
| PATCH | `/api/journals/:id/blocks/:blockId` | 单块更新（含 visibility） |
| POST | `/api/journals/:id/publish` | 校验 ≥1 个 public 块；生成 `shareToken`；可选审核 |
| POST | `/api/journals/:id/unpublish` | 回到 draft；保留 token 但公开 API 404 |
| DELETE | `/api/journals/:id` | 删除日记及块 |

### 8.2 公开 API（无需登录）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/share/journals/:token` | 只读日记；**仅 public 块**；`publish_status` 为 `published` 或 `unlisted` |
| GET | `/api/share/users/:handle/journals` | 公开列表（K-A4）；仅 `published` + `profile_blog_enabled` |

公开响应字段示例：

```json
{
  "title": "杭州三日漫行",
  "templateId": "diary-page",
  "themeId": "forest",
  "author": { "displayName": "...", "avatarUrl": "..." },
  "blocks": [ /* 仅 visibility=public 的块 */ ],
  "sharePath": "/share/journals/{token}"
}
```

### 8.3 错误码（须入 `ApiMessageKey`）

| Key | 场景 |
|-----|------|
| `JOURNAL_NOT_FOUND` | id/token 无效 |
| `JOURNAL_NOT_AVAILABLE` | 未发布或已撤回 |
| `JOURNAL_NO_PUBLIC_BLOCKS` | 发布时无公开块 |
| `JOURNAL_MODERATION_PENDING` | 审核中 |
| `JOURNAL_FORBIDDEN` | 非所有者操作 |

## 12. 风险与边界

| 项 | 策略 |
|----|------|
| 隐私泄漏 | 公开 API 单测覆盖 private 块；禁止客户端拼私有 id 拉取 |
| 存储成本 | 日记块仅存 JSON 元数据；媒体仍走 `travel_photos` / OSS |
| 与相册分享重复 | 相册保留「纯图集」；日记是 **叙事增强**，入口分流 |
| SEO | K-A4 再做 slug + meta；MVP token 链接不索引 |
| 范围膨胀 | MVP 不做拖拽编辑器、不做评论、不做关注流 |

**不做首版**：

- 访客评论 / 点赞日记  
- 多作者合写一篇日记  
- 独立域名 `{username}.douxing.com`（远期品牌能力）  
- 全文机器翻译

## 附录 A · 沉浸式公开页 UI 模式参考

> **用途**：从「重度主题化个人博客」类站点中 **抽象可复用 UI 模式**，供 K-A 公开页与 K-A5 模板扩展时对照；**不**绑定具体域名、游戏 IP 或 Halo/CMS 架构。  
> **原则**：只借鉴 **呈现层与阅读体验**；数据模型、块级隐私、模板注册表仍按本文 §5～§6 执行。

### A.1 使用边界

| 借鉴 | 不借鉴 |
|------|--------|
| 封面 Hero、元信息带、卡片列表、页脚人格化 | 整站 CMS、Markdown 自由排版替代 block |

## 附录 B · K-A5 安全主题候选（无 IP 依赖）

> **用途**：在 **不引入游戏/动漫 IP 素材** 的前提下扩展日记公开页视觉；色板与底纹与 H2 手帐海报 **同源**，便于 `poster/` 与 `journal-templates/` 共用。  
> **原则**：氛围来自 **自然景观意象 + 程序生成纹理 + 用户实拍**；禁止角色立绘、游戏 UI 皮肤、未授权壁纸包。

### B.1 与 H2 对齐的 `themes.ts` 结构

`packages/shared/src/journal-templates/themes.ts` 建议与现有 `PosterThemeVisual` 字段一致，并增加 Web 渲染专用元数据：

```ts
/** 与 packages/mobile|pc/src/poster/draw-poster-background.ts 中 PosterThemeVisual 同名字段对齐 */
export interface JournalThemeTokens {
  paper: string;      // 页面外缘 / 底纹区底色
  card: string;       // 主阅读卡片底色
  ink: string;        // 主标题、正文
  inkMuted: string;   // 副文案、meta
  accent: string;     // 强调、链接、day-header 色条
  footer: string;     // brand-footer 背景或文字
  columnBg: string;   // timeline-columns 列背景
}

/** 程序底纹类型（Canvas draw-* 或 CSS repeating-gradient 等价实现） */
export type JournalThemePattern =
  | 'line-cross'   // classic：细线 + 十字
  | 'line-dot'     // forest：斜线 + 点阵
  | 'wave-dot'     // ocean：波浪 + 点阵
  | 'dot-line'     // sunset：点阵 + 斜线
  | 'grid-minimal' // minimal：稀疏网格
  | 'contour'      // mountain：等高线弧
  | 'dune'         // desert：缓坡弧线
  | 'blossom-dot'  // cherry：稀疏圆点（自然樱花意象，无角色图）
  | 'star'         // night：星点
  | 'none';        // magazine / brand：靠排版与渐变，少底纹

export interface JournalThemeDefinition {
  id: JournalThemeId;
  /** K-A2 已交付 / K-A5 计划 / 远期实验 */
  phase: 'K-A2' | 'K-A5' | 'experimental';
  tokens: JournalThemeTokens;
  pattern: JournalThemePattern;
  /** 公开页 `<html data-theme>` 与 Tailwind CSS 变量前缀 */
  cssVarPrefix: `--journal-${string}`;
  /** 可选：标题字体栈（magazine 用衬线） */
  fontHeading?: string;
  /** i18n：journal.theme.{id}.name / .desc */
  i18nKey: string;
}

export type JournalThemeId =
  | 'classic' | 'forest' | 'ocean' | 'sunset'   // K-A2 · 与 PosterThemePresetId 一致
  | 'minimal' | 'mountain' | 'desert' | 'cherry' | 'night' | 'magazine' | 'brand'; // K-A5+
```

**类型约束**：K-A2 阶段 `JournalThemeId` 与 `PosterThemePresetId` 子集保持 **同名同值**，海报与公开页切换主题时共用 `POSTER_THEME_VISUALS` / `themes.ts` 一份 token。

### B.2 K-A2 已交付主题（MVP 必选）

与 H2-a+ 完全一致；底纹实现见 `fillThemedBackground()`。

| themeId | 阶段 | 意象 | pattern | 主色倾向 | 适合旅程 |
|---------|------|------|---------|----------|----------|
| `classic` | K-A2 | 米黄手帐纸 | `line-cross` | `#f7f0e3` / `#2c2416` | 通用默认 |
| `forest` | K-A2 | 森林徒步 | `line-dot` | `#f0f5f0` / `#1b4332` | 山林、公园、露营 |
| `ocean` | K-A2 | 海岸海岛 | `wave-dot` | `#eef4fa` / `#1d3557` | 海滨、湖泊、水上活动 |
| `sunset` | K-A2 | 晚霞暖调 | `dot-line` | `#fff8f0` / `#e85d04` | 沙漠、古城黄昏、秋日 |

### B.3 K-A5 安全扩展候选（建议优先级）

| 优先级 | themeId | 意象 | pattern | tokens 概要（paper / accent） | 适合旅程 | 备注 |
|--------|---------|------|---------|-------------------------------|----------|------|
| P1 | `minimal` | 极简留白 | `grid-minimal` | `#fafafa` / `#1677ff` | 城市、博物馆、商务差旅 | accent 可用 `--dx-primary`；少装饰 |
| P1 | `magazine` | 杂志大片 | `none` | `#ffffff` / `#1f2937` | 摄影向、大片游记 | 衬线标题；与 `diary-page` 模板强绑定 |
| P2 | `mountain` | 高原雪山 | `contour` | `#f4f6f8` / `#334155` | 川西、高原、徒步 | 等高线仅用 SVG/CSS 自绘 |
| P2 | `brand` | 兜行官方感 | `none` | 白卡 + 蓝绿渐变 Hero | 官方示例、广场精选 | 严格遵循 [品牌视觉规范](./品牌视觉规范.md) |
| P3 | `desert` | 戈壁沙丘 | `dune` | `#faf6f0` / `#b45309` | 西北、干旱地貌 | 与 `sunset` 区分：更沙、更少红 |
| P3 | `cherry` | 春日赏樱 | `blossom-dot` | `#fff5f7` / `#be185d` | 春季城市、公园 | **自然花卉意象**；禁止游戏角色/皮肤 |
| P3 | `night` | 夜景灯会 | `star` | `#0f172a` 外缘 + 浅卡正文区 | 夜景、节日灯会 | 正文区仍用浅色 `card` 保可读性 |

**首期 K-A5 建议只做 P1 两项**（`minimal` + `magazine`），验证模板与主题解耦后再加自然系 P2/P3。

### B.4 安全素材白名单 / 黑名单

| 类别 | 允许 | 禁止 |
|------|------|------|
| 底纹 | `draw-poster-background` 同类算法；CSS `repeating-linear-gradient` | 粉丝壁纸、游戏截图铺底 |
| 插画 | 通用 emoji 贴纸（H2 `PosterStickerId`）；自研 SVG 图标 | 角色立绘、游戏 Logo |
| 字体 | 系统栈；Noto Serif SC / Source Han Serif（遵许可证） | 游戏配套商业字体（未授权） |
| 图片 | 用户 `travel_photos`、景点 `cover_image_url`（内容库） | 未授权图库、爬虫图 |
| 动态 accent | K-A3+ 从封面图提取 dominant color 写入 `theme_options.accentOverride` | 整站外链皮肤包 |

### B.5 K-A3 可选增强：封面取色（仍无 IP）

不新增 `themeId`，仅在 `theme_options` 增加：

```ts
interface JournalThemeOptions {
  subtitle?: string;
  accentOverride?: string;  // 从 cover 图取主色，覆盖 tokens.accent
  usePhotoBackdrop?: boolean; // 封面图模糊铺底，叠 30～40% paper 色
}
```

公开 API **不返回** 私有照片 URL；`accentOverride` 仅作者预览与已公开封面关联。
