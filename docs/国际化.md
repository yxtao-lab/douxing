# 国际化（i18n）

兜行 Monorepo 使用 [vue-i18n](https://vue-i18n.intlify.dev/) 做前端界面多语言，当前支持 **简体中文（zh-CN）** 与 **English（en-US）**。

## 目录结构

```
packages/shared/src/i18n/     # 跨端共享文案（导航、Tab、会员等级等）
packages/mobile/src/i18n/     # 移动端专属文案 + 组合入口
packages/web/src/i18n/        # Web 管理端专属文案 + 组合入口
```

各端在 `index.ts` 中将 `shared` 与本地 `locales/*.ts` 浅合并为 `messages`：

```ts
messages: {
  'zh-CN': { ...sharedZhCN, ...mobileZhCN },
  'en-US': { ...sharedEnUS, ...mobileEnUS },
}
```

## 使用方式

### 模板

```vue
<text>{{ t('home.subtitle') }}</text>
<text>{{ t('home.welcome', { name: userName }) }}</text>
```

### 脚本（Composition API）

```ts
import { useI18n } from 'vue-i18n';

const { t, locale } = useI18n();
```

### 带变量的文案（移动端必读）

UniApp 部分运行环境下，模板里直接写 `t('key', { name })` 可能**不会替换** `{name}`。请使用 `useTf()`：

```ts
import { useTf } from '@/i18n/useTf';

const { t, tf } = useTf();
const welcomeText = computed(() => tf('home.welcome', { name: userName }));
```

`tf` 会先 `t(key)` 取模板，再用 `formatMessage` 替换 `{key}`。

**兴趣标签 `interestTags`**：数据库存中文预设值（如 `文化`），展示时用 `useInterestTagLabel()` 的 `labelOf` / `joinLabels`（定义在 `@douxing/shared` 的 `formatInterestTagLabel`）。

**不要用 `@{var}` 或 `{'@'}{var}`**：`@` 在 vue-i18n 里是链接语法；`{'@'}` 是编译期转义，UniApp 端常会原样显示。需要 `@用户名` 时，在模板写 `@{{ text }}`，文案里只保留 `{username}` 等普通占位符。

### 移动端导航栏标题

`pages.json` 中的 `navigationBarTitleText` 仅作构建占位；页面内调用：

```ts
import { usePageTitle } from '@/i18n/usePageTitle';

usePageTitle('nav.plan');
```

切换语言后会通过 `watch(locale)` 自动更新标题。

### 切换语言

| 端 | 入口 | 持久化 |
|----|------|--------|
| 移动端 | 我的 → 个性化 → 语言 | `uni.setStorageSync('douxing_locale')` |
| Web | 顶栏或登录页语言下拉 | `localStorage['douxing_locale']` |

未手动选择时，首次启动按系统/浏览器语言推断（`en*` → en-US，否则 zh-CN）。

## 新增文案规范

1. **键名**：按页面或模块嵌套，如 `plan.promptPlaceholder`，使用 camelCase 段。
2. **共享 vs 专属**：Tab、导航、会员等级等放 `shared`；仅单端出现的放 `mobile` / `web`。
3. **禁止**在组件内硬编码用户可见中文/英文（品牌符号「兜」等装饰除外）。
4. 带参数的文案使用 vue-i18n 插值：`{count}`、`{name}`。

### 会员等级示例

```ts
import { getMemberLevelI18nKey } from '@douxing/shared';

const label = t(getMemberLevelI18nKey(user.memberLevel));
```

## 接口国际化（API）

### 响应格式

```json
{
  "code": 1,
  "messageKey": "api.unauthorized",
  "message": "Not signed in",
  "data": null
}
```

- `message`：已按请求语言翻译，**客户端优先直接展示**
- `messageKey`：稳定标识，便于埋点或离线兜底翻译

### 请求头

移动端 / Web 请求会自动附带：

```http
Accept-Language: zh-CN
```

与界面语言 `douxing_locale` 保持一致。服务端 `localeMiddleware` 解析后写入 `res.locals.locale`。

### 服务端用法

```ts
import { ApiMessageKey } from '@douxing/shared';
import { fail, success, failFromError } from '../utils/response.js';

fail(res, ApiMessageKey.USER_NOT_FOUND, 404, 404);
success(res, data, ApiMessageKey.PROFILE_UPDATED);

// 业务层
throw new ApiError(ApiMessageKey.SMS_RATE_LIMIT, { seconds: 30 });
```

历史 `fail(res, '未登录')` 仍可用：通过 `API_LEGACY_MESSAGE_MAP` 自动映射到 `messageKey` 并翻译。

文案表：`packages/shared/src/i18n/api-messages.ts`  
键名常量：`packages/shared/src/i18n/api-keys.ts`

## 扩展新语言

1. 在 `packages/shared/src/i18n/types.ts` 的 `LocaleCode`  union 中增加语言码。
2. 在 `SUPPORTED_LOCALES` 中注册选项。
3. 为 `shared`、`mobile`、`web` 各新增一份 `locales/<code>.ts`。
4. 在对应端 `i18n/index.ts` 的 `messages` 中注册。

pnpm --filter @douxing/shared build
