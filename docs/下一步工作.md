## 开发环境自检（当前）

开发环境**默认不配 OSS**（`OSS_ENABLED` 未设或为 false），封面写入 `packages/server/uploads/attractions/`，DB 存 `/uploads/attractions/...`，接口用 `API_PUBLIC_BASE_URL`（或请求 Host）拼完整 URL。

### 封面 enrich（A2+++ · 开发环境）

前置：`.env` 中配置 `AMAP_WEB_KEY`（`AMAP_IMAGE_ENRICH_ENABLED` 默认跟随 `AMAP_ENABLED`）；Wikimedia 兜底默认开启（`WIKIMEDIA_IMAGE_ENRICH_ENABLED` 非 `false` 即可）。

> 也可用根目录脚本：`pnpm enrich:attraction-images -- --dry-run --limit=5`（npm：`npm run enrich:attraction-images -- --dry-run --limit=5`）。包管理说明见 [包管理与命令.md](./包管理与命令.md)。

```bash
# 预览补全，不写库
pnpm enrich:attraction-images -- --dry-run --limit=5

# 正式补全无封面景点（写本地盘）
pnpm enrich:attraction-images -- --limit=20
```

**开发环境通过标准（不做生产 OSS）：**

- [ ] CLI 或路线同步后，无封面景点能补上图；日志 `source=amap` 或 `source=wikimedia`
- [ ] DB 中 `cover_image_url` 为 `/uploads/attractions/{id}-amap|wikimedia|manual.*`；`uploads/attractions/` 下文件存在
- [ ] Web 管理端：景点列表缩略图可见；「重新拉取封面」对非 `manual` 来源可用
- [ ] 移动端 H5：路线详情流程图、分享页、手帐海报 POI 区能显示封面（URL 形如 `http://localhost:3000/uploads/attractions/...`）

**开发环境不需要做：** `migrate:covers-to-oss`、`cleanup:orphan-covers`（除非本地刻意开启 OSS 做联调）、CDN 域名、小程序合法域名。
