### 0.3 三条原则（执行过程中不可违背）

1. **模块 B 与模块 A 分表分 API** — 不在 `travel_routes` / `plan_sessions` / 现有 `orders` 上增发单字段。
2. **弱耦合可选** — `service_demand.route_id` 仅作参考；**禁止**把发单嵌入 AI 规划主流程。
3. **商户组织 ≠ 平台部门** — `biz_org` / `org_member` 与 `sys_dept` 分离；平台 RBAC 与商户 `org_id` 数据隔离并存。

## 1. 双模块与边界（摘要）

```text
兜行平台
├── 模块 A：AI 旅行规划（默认主链）
│   plan_sessions · travel_routes · check_ins · orders（路线解锁）
│
└── 模块 B：发单接单（本路线图）
    service_demand · demand_quote · service_order · biz_org
    API：/api/marketplace/*
```

| 能力 | 归属 | 数据域 |
|------|------|--------|
| AI 多轮规划 | A | `plan_sessions` |
| 搭子匹配 | D | `match_requests`（≠ `service_demand`） |
| 路线解锁付费 | A | `orders` |
| 发单 / 报价 / 履约 | **B** | `service_*` |
| 服务者认证 / 预约 | **B**（原 E4/E5 落地） | `biz_org` / `service_provider` |

## 10. 维护约定

> **强制**：M 线阶段状态发生变更（启动 / 步骤完成 / 阶段验收 / 指针切换）后，**须在同一次交付中**更新本文，不得仅改代码不改正文。  
> **Agent 规则**：`.cursor/rules/marketplace-roadmap-sync.mdc`（编辑 marketplace 代码或本文时自动生效）。

### 10.1 何时更新

| 触发事件 | 必须更新的位置 |
|----------|----------------|
| **启动某 Phase**（如开始 M2） | §0.1 当前步 · §0.2 进度条 · 对应 Phase 标题改为「当前」 |
| **完成某 Step** | §3 对应行状态 `[ ]` → `[x]` · 勾选验收标准 |
| **阶段验收通过**（如 `m1:*-cases` 全绿） | §2 里程碑 `[x]` + 日期 · §0.1 上一阶段 / 当前步 · §0.2 进度条 · §4 依赖图 |
| **指针切换**（当前步 → 下一阶段） | §0.1 全部字段 · §0.2 · 变更记录 |
| **新增/变更 API** | §3 交付落点 · **M1-9 类文档 Step** · `API接口文档.md` §25 · `openapi.yaml` |
| **已知范围外缺口**（如 M1 无 C 端表单） | §0.1「已知缺口」或 Phase 末尾「不做 / 归某 Step」 |

### 10.2 更新顺序（建议）

1. 跑通验收命令（§6），确认全绿后再改文档状态。
2. 更新 **§3 Step 表** → **§2 里程碑** → **§0 当前指针** → **§4 依赖图**（若阶段完成）。
3. 同步 **[下一步工作.md](./下一步工作.md)** M 线表格与 **[ROADMAP.md](./ROADMAP.md)** § 阶段 M 一行摘要。
4. 同步 **[发单接单平台.md](./发单接单平台.md)** 文首「实施状态」与 M 线状态表（若有）。
5. 在 **变更记录** 追加一行：日期 · 版本号 · 完成了什么 · 指针指向哪里。

### 10.3 状态标记规范

| 标记 | 含义 |
|------|------|
| `[ ]` | 未开始 |
| `[~]` | 进行中（已开工、未验收） |
| `[x]` | 已验收（对应 `mN:*-cases` 全绿或等价手测通过） |

- Phase 标题：`（P0 · ✅ 2026-07-09）` = 已验收；`（P0.5 · 当前）` = 进行中。
- **禁止** 仅改 §0 指针而不改 §3 Step 表（或反之）。

### 10.4 版本号

- 小改（单 Step 完成、扫尾）：补丁 +0.0.1（如 1.2.0 → 1.2.1）。
- 整阶段验收 / 里程碑达成：次版本 +0.1.0（如 1.1.1 → 1.2.0）。
- 文首 **最后更新** 行须写清：验收项 · 迁移号 · 验收命令 · **指针 → 下一阶段**。
