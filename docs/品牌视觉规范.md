## 1. 品牌定位

| 维度 | 约定 |
|------|------|
| **产品名** | 兜行（Douxing） |
| **Logo 字标** | 单字「兜」，用于 App 内圆形/圆角矩形容器；非独立 Logo 文件时勿随意改字 |
| **调性** | **旅行探索感** — 可执行的 AI 行程，而非纯工具灰界面 |
| **主视觉** | 蓝绿渐变 Hero + 白卡片内容区 + 地图/行程隐喻（emoji / iconfont 过渡，后续可换插画） |
| **禁止** | 对外文案出现「MVP」「体验账号」等内部用语；硬编码中文/英文用户可见文案（见 [国际化.md](./国际化.md)） |

## 2. 设计 Token

在 `App.vue` 全局引入：

```css
@import '@/styles/theme.css';
```

所有新页面与组件 **优先使用 CSS 变量**，禁止新增散落的主色 hex（`#1677ff` 等应写为 `var(--dx-primary)`）。

| `--dx-primary-light` | `#e8f3ff` | Chip 背景、次要按钮底、空状态描边 |
| `--dx-accent` | `#13c2c2` | 渐变终点、注册态、强调 |
| `--dx-accent-dark` | `#08979c` | 注册主按钮、注册 Hero |
| `--dx-accent-soft` | `#e6fffb` | 体验提示框、轻强调背景 |
| `--dx-bg` | `#f5f7fa` | 页面底色 |
| `--dx-surface` | `#ffffff` | 卡片、表单、主 CTA 白底 |

## 3. 色彩系统

### 3.1 主色（登录 / 默认操作）

- **Primary Blue**：行动召唤（CTA）、选中态、链接
- 使用场景：「开始规划」、路线详情 CTA、用户聊天气泡

### 3.2 辅色（注册 / 次要强调）

- **Accent Teal**：与主色区分模式，不替代全局主色
- 使用场景：密码 Tab 下「注册」态 Hero、注册提交按钮

### 3.3 功能色（保持现有语义，不纳入 `--dx-*`）

| 语义 | 参考色 | 场景 |
|------|--------|------|
| 成功 | `#059669` / `#ecfdf5` | LLM 就绪、成就 |
| 警告 | `#d97706` / `#fff7ed` | LLM 降级、开发验证码 |
| 错误 | `#cf1322` / `#fff2f0` | 表单错误、追问锁定 |
| 会员 | `#b45309` / `#fff7ed` | 会员提示条 |

### 3.4 对比度

- Hero 上文字使用 `--dx-text-inverse` 或 `rgba(255,255,255,0.88+)` 副文案
- 白卡片上主文案 `--dx-text`，次级 `--dx-text-secondary`

## 4. 字体与层级

**字体栈**（`App.vue` → `page`）：

```css
font-family: -apple-system, BlinkMacSystemFont, 'PingFang SC', 'Microsoft YaHei', sans-serif;
```

### 4.1 字号层级（移动端 rpx）

| 级别 | 字号 | 字重 | 示例 |
|------|------|------|------|
| H1 / 品牌名 | 40～44rpx | 700 | 首页「兜行」、登录品牌名 |
| H2 / 区块标题 | 32～34rpx | 700 | 表单标题、空状态标题 |
| H3 / 卡片标题 | 30～32rpx | 600 | 路线名、规划页标题 |
| 正文 | 28rpx | 400 | 输入、气泡正文 |
| 辅助 | 24～26rpx | 400～500 | 描述、meta、标签 |
| 脚注 | 22rpx | 400 | 提示、免责声明 |

### 4.2 行高

- 标题：`1.35～1.45`
- 正文/气泡：`1.5～1.6`

## 5. 圆角、间距与阴影

### 5.1 间距（建议）

| 场景 | 数值 |
|------|------|
| 页面左右边距 | `32～40rpx`（首页/登录已用 `40rpx`） |
| 卡片内边距 | `28～44rpx` |
| 区块间距 | `24～32rpx` |
| Tab 页底栏留白 | `calc(120rpx + env(safe-area-inset-bottom))` |

### 5.2 圆角

- 按钮 / 主 CTA：`--dx-radius-lg`（24rpx）
- 标准卡片：`--dx-radius-md`～`--dx-radius-xl`
- Chip / 标签：`999rpx` 胶囊

### 5.3 阴影

- 列表卡片：`--dx-shadow-sm`
- 主按钮、登录 Sheet：`--dx-shadow-md`
- Hero 区域：`--dx-shadow-hero`（注册态用 `--dx-shadow-hero-register`）

## 6. 渐变与 Hero

### 6.1 结构模式

```text
┌─────────────────────────────┐
│  hero-bg（全宽渐变 + 下圆角） │
│  hero-safe（状态栏/胶囊留白）   │
│    hero-content（居中/左对齐）  │
└─────────────────────────────┘
┌─────────────────────────────┐
│  sheet-card（白卡片，负 margin │  ← 可选叠层
│  与 Hero 衔接）                │
└─────────────────────────────┘
```

### 6.2 实现要点

- **背景**：`hero-bg` `position: absolute; inset: 0`，渐变 `--dx-gradient-hero`
- **安全区**：使用 `utils/safe-area.ts` → `buildCustomNavTopPadding()`（小程序对齐胶囊底部）
- **custom 导航栏**：登录页等使用 `navigationStyle: custom`，**不展示系统返回按钮**
- **Logo 容器**：半透明白底 + 白字「兜」，圆角 `--dx-radius-lg`～`--dx-radius-xl`

### 6.3 价值主张 Chip

- 半透明白底 `rgba(255,255,255,0.16～0.18)` + 细白描边
- 首页/登录 Hero 内横向居中排列

## 7. 组件规范

### 7.1 主按钮（Primary CTA）

```css
background: var(--dx-primary);
color: var(--dx-text-inverse);
height: 88rpx;
border-radius: var(--dx-radius-lg);
box-shadow: var(--dx-shadow-md);
font-size: 30～32rpx;
font-weight: 600;
```

- 白底主 CTA（Hero 内）：`background: var(--dx-surface); color: var(--dx-primary);`

### 7.2 次级 / Ghost 按钮

- 背景 `--dx-primary-light` 或 `--dx-surface` + `--dx-primary-light` 描边
- 见 `DouxingEmptyState` 的 `dx-empty-btn--ghost`

### 7.3 胶囊 Tab（登录模式切换）

- 外层：`background: var(--dx-bg); padding: 8rpx; border-radius: --dx-radius-lg`
- 选中项：白底 + 主色文字 + `--dx-shadow-sm`

### 7.4 Chip（快捷 prompt / 筛选）

- 默认：`background: --dx-primary-light; color: --dx-primary; border-radius: 999rpx`
- 选中：实心主色底 + 白字

### 7.5 输入框

- 高度 `88rpx`，边框 `2rpx solid --dx-border`，圆角 `--dx-radius-md`
- 聚焦：`border-color: --dx-primary`（注册态 `--dx-accent`）

### 7.6 空状态 `DouxingEmptyState`

**路径**：`packages/mobile/src/components/douxing-empty-state/`

| Prop | 说明 |
|------|------|
| `variant` | `routes` / `plaza` / `achievements` / `checkins` / … |
| `title` / `description` | 主副文案（走 i18n） |
| `actionLabel` / `secondaryActionLabel` | 主/次 CTA |
| `compact` / `embedded` | 紧凑 / 卡片内嵌 |
| `loading` | 加载 spinner |

**插画位**：圆形 `--dx-gradient-soft` + emoji（后续可换 SVG/PNG，保持 160rpx 直径）。

### 7.7 聊天气泡（规划页）

| 角色 | 背景 | 圆角 |
|------|------|------|
| 用户 | `--dx-primary` | 右下角小圆角 `4rpx` |
| 助手 | `--dx-surface` + `--dx-shadow-sm` | 左下角小圆角 |
| 助手头像 | 品牌绿渐变或 `--dx-gradient-hero` 简化版 | 圆形 72rpx |

### 7.8 路线候选卡片

- 默认：白底 + `--dx-border` 描边
- 选中：`border-color: --dx-primary`，背景 `#f0f7ff` 或 `--dx-primary-light`

## 9. 登录 / 注册双色态

仅在 **密码 Tab** 且 `isRegister === true` 时启用 class `login-page--register`：

| 元素 | 登录（蓝） | 注册（青） |
|------|-----------|-----------|
| Hero 渐变 | `--dx-gradient-hero` | `--dx-gradient-hero-register` |
| 主按钮 | `--dx-primary` | `--dx-accent-dark` |
| 表单卡片描边 | 透明 | `rgba(19,194,194,0.2)` |
| Tab 高亮 / 链接 | `--dx-primary` | `--dx-accent-dark` |

验证码 Tab 始终为**登录蓝调**（自动注册，无单独注册色）。

## 12. 工程约定

### 12.1 新增页面检查

1. 使用 `--dx-*` Token，不新增硬编码主色
2. 空列表使用 `DouxingEmptyState`
3. 文案走 i18n
4. custom 导航页调用 `buildCustomNavTopPadding()`
5. 修改 `theme.css` 后更新**本文档 §2.1**

### 12.2 H5 rem / rpx 适配

移动端样式统一写 **rpx**（750 设计宽）。各端行为：

| 端 | 单位 | 说明 |
|----|------|------|
| 微信小程序 / App | rpx | 平台原生换算 |
| **H5** | rpx → rem | PostCSS 编译；根字号由框架按视口写入 `html` |

**H5 约定（与 750 稿一致）**

- `manifest.json` → `h5.rpx`：`unitRatio: 0.01`，即 **100rpx = 1rem**（Safari 调试更直观）
- `pages.json` → `globalStyle`：`remCalcDesignWidth: 750`、`remCalcDesignFontSize: 100`（375px 宽时根字号 50px）
- 宽屏：`rpxCalcMaxDeviceWidth: 960`、`rpxCalcBaseDeviceWidth: 375`，超过 960px 宽不再继续放大
- `styles/h5-viewport.css`：≥481px 时 body 最大宽 480px 居中；`-webkit-text-size-adjust: 100%` 防 iOS 改字号

**不要**在 H5 再手写 `document.documentElement.style.fontSize`，会与 uni 的 resize 逻辑冲突并导致闪动（见 [DCloud 问答](https://ask.dcloud.net.cn/article/42371)）。

## 13. 验收清单

新做或改版页面合并前自检：

- [ ] 主色/辅色来自 `--dx-*`，无新增 `#1677ff` 散落
- [ ] 用户可见文案已入 zh-CN / en-US
- [ ] 空状态使用 `DouxingEmptyState`（非单行灰字）
- [ ] Tab 页底部内容不被 `DouxingTabBar` 遮挡
- [ ] custom 导航页顶栏不遮挡（真机微信小程序）
- [ ] 生产包无体验账号预填与 demo 提示
- [ ] en-US 下 Hero/卡片无明显破版
