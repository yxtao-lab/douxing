## 8. 发单接单平台（模块 B）合规

> 与 [发单接单平台.md](./发单接单平台.md) · ROADMAP **M 线** 相关；**代码侧 M0～M7 / E2 接线已落地**，资质与真机支付仍依赖合规办结。

| 项 | 说明 |
|----|------|
| **旅行社** | 接单方需有效 **旅行社业务经营许可证**；平台留存审核记录 |
| **导游 / 领队** | 向导类目建议校验导游证等；户外领队需安全与保险产品规则 |
| **摄影 / 模特** | 一般无强制行业许可；**实名认证（H6）** + 作品集审核 |
| **团体出行** | 班级研学、未成年人团需知情同意与安全预案（产品规则，非纯代码） |
| **支付与结算** | `service_order` **通道接线 ✅**；沙箱/正式真付仍依赖 **商户号、对公账户**；与路线解锁 `orders` 分表 |
| **发票** | 公司团建等字段已支持（M3）；开票流程与税控对接待评估 |

**解锁能力：** 完成公司主体 + 支付商户后，可做 **沙箱真机一笔** 收口完整 MB4，并推进商户提现。
