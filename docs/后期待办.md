# 后期待办

> 记录当前阶段**暂无法推进**或**依赖外部资质/审核**的事项，便于后续逐项落地。  
> 与 [ROADMAP.md](./ROADMAP.md)（功能开发计划）区分：本文侧重**合规、资质、第三方审核**等非纯代码工作。

**最后更新：** 2026-05-26

---

## 1. 微信小程序备案

| 项 | 说明 |
|----|------|
| **现状** | 未完成小程序 ICP 备案，正式上架/部分能力可能受限 |
| **待办** | 在 [微信公众平台](https://mp.weixin.qq.com/) 按指引提交小程序备案 |
| **前置** | 通常需已注册公司、已备案域名、主体信息与小程序 AppID 一致 |
| **关联** | 见下文「注册公司」 |

---

## 2. 微信小程序语音插件（同声传译）

| 项 | 说明 |
|----|------|
| **现状** | 公众平台插件市场搜索「同声传译」无结果，WechatSI 插件无法添加 |
| **当前方案** | 已改为 **录音 + 服务端腾讯云 ASR**（`POST /api/speech/transcribe`），不依赖微信插件 |
| **待办（可选）** | 若后续微信开放插件或提供官方语音识别能力，可评估是否切回客户端识别以降本 |
| **备注** | App / H5 不受此限制（App 走服务端 ASR，H5 走 Web Speech API） |

---

## 3. 支付模块

| 项 | 说明 |
|----|------|
| **现状** | 代码侧已有微信支付/mock 等能力（见 [移动端支付联调说明.md](./移动端支付联调说明.md)），**商户号与正式联调未完全打通** |

| **前置** | 注册公司、对公账户、小程序与企业主体一致 |
| **关联** | 见下文「公司对公账户办理」 |

## 4. 短信模块 — 企业认证重新认证

| 项 | 说明 |
|----|------|
| **现状** | 短信走腾讯云（`SMS_PROVIDER=tencent`），开发环境可用 mock；**企业实名/短信资质若过期或未通过，生产无法发真实验证码** |
| **待办** | 登录 [腾讯云短信控制台](https://console.cloud.tencent.com/smsv2) 完成/重新完成 **企业认证**；更新签名、模板审核状态 |
| **配置** | 根目录 `.env`：`TENCENT_SECRET_ID`、`TENCENT_SECRET_KEY`、`TENCENT_SMS_SDK_APP_ID`、`TENCENT_SMS_SIGN_NAME`、`TENCENT_SMS_TEMPLATE_ID` |
| **前置** | 公司主体与腾讯云账号实名信息一致 |

## 5. 注册公司

| 项 | 说明 |
|----|------|
| **现状** | 未作为正式商业主体运营，影响备案、支付、短信、对公账户等 |
| **待办** | 选定注册地与公司类型 → 核名 → 登记 → 领取营业执照 |
| **解锁能力** | 小程序企业主体备案、微信支付商户、腾讯云企业认证、短信签名、对公账户 |
| **备注** | 具体流程以当地市场监管部门及代办政策为准 |

## 6. 公司对公账户办理

| 项 | 说明 |
|----|------|
| **现状** | 未开立对公账户 |
| **待办** | 凭营业执照、法人身份证等材料到银行开立 **基本存款账户（对公户）** |
| **用途** | 微信支付结算、部分平台企业验证、合同与发票收款 |
| **前置** | 完成「注册公司」 |
| **关联** | 支付模块正式商户进件、财务合规 |

## 建议推进顺序

```text
注册公司
  → 公司对公账户
  → 腾讯云企业认证 / 短信重新认证
  → 微信小程序备案
  → 微信支付商户与支付模块联调
  → （可选）关注微信语音插件政策变化
```
