## 9. 精准化与人群定制隐私合规（2026-07-17 录入）

> **关联**：[精准化与人群定制路线图.md](./精准化与人群定制路线图.md) · ROADMAP §9.10 · `P-PROFILE-01` / `P-ONBOARD-01`

### 9.1 涉及个人信息字段

| 字段 | 类别 | 合规要求 |
|------|------|----------|
| `gender` | 性别 | 自愿填写；可「不愿透露」；不对外公开 |
| `birthYear` / `ageRange` | 年龄 | 仅收集年龄段（不收集未成年人精确出生日期）；可控制可见性（`ageVisibility`：不公开/仅年龄段/公开年龄） |
| `preferredScenes` | 旅行偏好 | 用于推荐；不对外公开 |
| `companionStructure` | 同伴结构 | 用于推荐；不对外公开 |
| `budgetTier` | 预算档次 | 用于推荐；不对外公开 |
| `onboardedAt` | 引导完成时间 | 内部审计；不对外公开 |

### 9.2 隐私政策更新要求

落地 `P-ONBOARD-01` / `P-PROFILE-01` 前，隐私政策须同步更新，至少包含：

1. **收集范围**：性别、年龄段、旅行偏好、同伴结构、预算档次
2. **使用目的**：个性化推荐、规划注入、主题推荐
3. **自愿原则**：所有字段可跳过、可「不愿透露」、可随时修改
4. **不公开**：画像字段仅用于推荐，不对其他用户公开（年龄段可按用户设置公开为「年龄段」或「精确年龄」）
5. **未成年人保护**：不收集未成年人精确信息；未成年人社交匹配禁止
6. **数据删除**：用户可一键清除画像重置为默认（`DELETE /api/users/me/persona`）
7. **审计**：画像字段写入与修改记录审计日志

### 9.3 实时人数隐私（P-LIVE-01）

- 打卡计数 < 阈值（默认 5）时仅展示「人少」语义，不暴露具体数字
- 不展示个体行踪；仅展示聚合档位

### 9.4 合规阻塞

- `P-PROFILE-01` 同龄人社交功能依赖 **隐私政策更新** + **未成年人保护条款**
- 未完成隐私政策更新前，`P-ONBOARD-01` 可先上线非敏感字段（旅行半径/旅行场景/兴趣类型），性别/年龄段字段后置

## 10. 对公账户办理之后可完善工作清单

> **录入日期**：2026-07-17
> **背景**：公司主体与对公账户办理中（见 §5 / §6）；本节汇总对公户到手后可立即推进的事项，作为逐项落地清单。条目状态用 `[ ]` 待办 / `[x]` 完成 / `[~]` 进行中 标记。

### 10.1 支付收口（最高优先 · 收口 MB4）

- [ ] **微信支付商户号进件**：用对公户打款验证，申请商户号（类目选「平台 / 信息服务」，勿选「旅行社」）
- [ ] **配置 `WECHAT_PAY_*` 环境变量**：`WECHAT_PAY_MCH_ID` / `WECHAT_PAY_APP_ID` / `WECHAT_PAY_API_V3_KEY` 等，见 `deploy/env.production.example`
- [ ] **支付 notify 域名 HTTPS 配置**：生产用已部署 HTTPS notify，本地调试才需内网穿透
- [ ] **沙箱真机支付一笔**：收口完整 **MB4**（M6-5 / M7-6 验收最后一项）
- [ ] **微信退款实装**：替换当前 `refund` 占位逻辑

### 10.2 平台资质类

- [ ] **腾讯云账号企业实名认证**：对公户打款验证或上传执照 + 开户许可证
- [ ] **腾讯云短信签名 / 模板重新审核**：通过后 `SMS_PROVIDER=tencent` 可上生产发真实验证码
- [ ] **微信小程序 ICP 备案**：主体信息与 AppID 一致
- [ ] **品牌域名注册**：`douxingai.com`（首选）/ `douxingtravel.com`（备选），见 §7
- [ ] **品牌域名 ICP 备案**：备案主体需对公户支撑
- [ ] **域名 HTTPS 配置**：支付 notify 与小程序合法域依赖

### 10.3 财务合规类

- [ ] **商户结算打款到对公户**：`org_settlement` 台账真实打款链路打通
- [ ] **发票真开票流程**：M3-3 `invoice_info` 字段已支持，对接税控开票
- [ ] **合同与发票对外正式收款**：对公户作为收款账户
- [ ] **注册资本实缴**（如认缴制下需实缴）：股东出资款打人对公户，备注「投资款」，保留银行回单

### 10.4 税务联动

- [ ] **签订三方协议**（公司 — 银行 — 税务）：开通网上扣税
- [ ] **按期税务申报**：增值税、企业所得税、个税、附加税（即使零收入也需申报）
- [ ] **社保 / 公积金开户**：绑定对公户自动扣缴
- [ ] **建立「三流一致」档案**：发票 / 银行流水 / 合同对应归档

### 10.5 可选 / 远期

- [ ] **增值电信 EDI 评估**：模块 B 规模化平台结算时评估
- [ ] **独立 `packages/partner` 子应用**：商户工作台独立部署（远期）
