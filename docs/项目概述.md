# 兜行（Douxing）工作区说明

## 1. 适用范围

本文件适用于当前工作区 `project/`，为 **pnpm / npm workspaces Monorepo**（推荐 pnpm），目录如下：

```
project/
├── packages/
│   ├── web/        # @douxing/web      — Vue 3 管理端（兜行管理后台）
│   ├── pc/         # @douxing/pc       — Vue 3 PC 用户端（C 端桌面，:5176）
│   ├── mobile/     # @douxing/mobile   — UniApp 移动端（H5 / 微信小程序 / Android / iOS）
│   ├── server/     # @douxing/server   — Node.js + Express 后端 API
│   ├── shared/     # @douxing/shared   — 跨端共享类型、常量、i18n
│   ├── ai-service/ # @douxing/ai      — Python FastAPI + LangChain 微服务（可选）
│   └── ml-training/# @douxing/ml      — 专属模型 LoRA 训练数据管线
├── docs/           # 文档：详细设计、路线图、开发记录、品牌规范等
├── scripts/        # 部署 / 引导 / 诊断脚本（说明见 scripts/README.md）
└── deploy/         # 生产环境配置模板
```

### 默认工作方式

- **所有子包在同一 Git 仓库内**，`git status`、`git diff`、提交等均在根目录执行
- 各子包通过 workspace filter 精确操作（pnpm：`pnpm --filter`；npm：`npm run -w`），根脚本由 `scripts/pm.mjs` 统一转发
- 共享包 `@douxing/shared` 修改后影响三端，无需发布
- 根目录 `.env` 供**后端**运行时使用；**前端 API** 在 `.env.local`（dev）或 `.env.staging` / `.env.production`（打包）
- 开发执行 `pnpm dev`（全端含 AI；**Web 管理端 :5173、PC 用户端 :5176 就绪后自动打开浏览器**）或 `pnpm dev:only <平台>`；`pnpm env:status` 查看当前 API 地址

## 2. 业务范围默认认知

兜行定位为 **AI 驱动的个性化旅游决策与社交平台**，并扩展 **旅行及相关服务的发单接单 marketplace（按需启用）**。

### 双模块架构（2026-06-09 定稿）

| 模块 | 说明 | 文档 |
|------|------|------|
| **A · AI 旅行规划** | 个人自助游：规划、路线、打卡、成就、手帐（**默认主链**） | ROADMAP A/B/C/H/J/P |
| **B · 发单接单** | 个人/团体发单，旅行社、领队、摄影团队等接单；**与 A 独立** | [发单接单平台.md](./发单接单平台.md) |

平台运营后台（用户/角色/权限）：[系统管理.md](./系统管理.md) · ROADMAP **S 线**。

### 主链路：AI 规划 → 手帐分享（模块 A）

```
用户输入一句话需求
       ↓
  AI 意图解析（城市/天数/预算/主题）
       ↓
  RAG 景点检索（内容库匹配）
       ↓
  生成 2~3 套候选路线（多方案）
       ↓
  多轮对话追问优化（单方案收敛）
       ↓
  后端 Enricher 增强（交通/住宿/班次/玩法）  ← H9 已完成
       ↓
  路线发布 / 公开到广场
       ↓
  生成手帐海报（选模板 → Canvas → 保存/分享）  ← H2-a + D5-a 已完成
       ↓
  【规划】旅程相册：按天/POI 存旅行照 · 会员配额  ← J 线，见 docs/旅行照片存储系统.md
```

### 次级链路：打卡 → 成就/徽章 → 排行榜 → 旅程相册

```
到达景点 → GPS 围栏打卡（含 attractionId，可选照片）
       ↓
  自动触发成就解锁（8 种，配置化）
  自动触发徽章解锁（11 种，含进度系统）
       ↓
  排行榜（周榜/月榜，按打卡数/积分）
       ↓
  打卡地图聚合展示（移动端 UniApp map · Web/PC Leaflet + 高德瓦片）
       ↓
  【规划 J4】打卡照片归并进该路线旅程相册 → 手帐/地图统一选图
       ↓
  【规划 F 线】3D 路线预览 / 足迹孪生 / 景点全景与模型（PC-first，见 docs/数字孪生与三维建模.md）
```

### 商业链路

**模块 A（现有）：** 路线解锁订单 → 模拟/微信支付 → 查看完整行程  

**模块 B（规划 · M 线）：** 发单 → 报价 → 履约 `service_order` → 平台结算（与路线解锁 **分表**）  

详见 [发单接单平台.md](./发单接单平台.md)。

### AI 模型策略

| 模式 | 说明 |
|------|------|
| `auto`（默认） | 优先 DeepSeek，失败降级 LM Studio，再降级模板 |
| `deepseek` | 仅云端 DeepSeek API |
| `lmstudio` | 仅本地 LM Studio |
| 专属模型（待上线） | PAI LoRA 微调 + 百炼推理，见 I2/I3 |

## 5. 常用命令速查

> 下表为 **pnpm** 写法；**npm** 将 `pnpm <脚本>` 改为 `npm run <脚本>`，带平台参数时加 `--`（如 `npm run dev:only -- server,web`）。完整对照见 [包管理与命令.md](./包管理与命令.md)。

| 用途 | 命令（pnpm） |
|------|----------------|
| 启动全部开发服务 | `pnpm dev`（Web :5173 + PC :5176 自动打开浏览器） |
| Web 管理端 | `pnpm dev:web` 或 `pnpm dev:admin`（后端+管理端） |
| PC 用户端 | `pnpm dev:pc` 或 `pnpm dev:only server,pc`（`:5176`） |
| 单端启动 | `pnpm dev:only server,web,mobile` |
| 数据库迁移 | `pnpm db:migrate` |
| 数据库种子 | `pnpm db:seed` |
| 全量构建 | `pnpm build` |
| 生产部署后端 | `pnpm deploy:server` |
| 原生 App 一键构建 | `pnpm deploy:app` |
| ML 数据集生成 | `pnpm ml:generate-dataset` |
| ML 数据集校验 | `pnpm ml:validate-dataset` |

详细命令表见 [README.md](../README.md#命令速查)。
