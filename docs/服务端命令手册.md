# 兜行 · 服务端命令手册

> 在**生产服务器**（默认 `/opt/douxing`）上执行的命令速查。  
> 关联：[发版流程与 CI/CD 解析](发版流程与CI-CD解析.md) · [生产部署指南](deploy-production.md) · [scripts 说明](../scripts/README.md)

**原则**

- 服务器只做 **`git pull`**，不要 `git add` / `commit` / `push`
- 日常发版：**本地 push → Gitee Webhook 自动构建**（无需 SSH）
- 所有命令默认在项目根目录：`cd /opt/douxing`

---

## 1. 域名与目录

| 域名 | 用途 | 静态/反代 |
|------|------|-----------|
| `api.yxtao.site` | 后端 API | → `127.0.0.1:3000` |
| `pc.yxtao.site` | PC 用户端 | `/opt/douxing/static/pc` + `/api` 反代 |
| `web.yxtao.site` | Web 管理端 | `/opt/douxing/static/web` + `/api` 反代 |
| `hooks.yxtao.site` | Webhook（可选） | → `127.0.0.1:9090` |

| 路径 | 说明 |
|------|------|
| `/opt/douxing` | 项目根目录 |
| `/opt/douxing/.env` | 生产环境变量（**不入 Git**） |
| `/opt/douxing/static/pc` | PC 构建产物 |
| `/opt/douxing/static/web` | Web 管理端构建产物 |
| `/opt/douxing/logs/` | 发版与运行日志 |
| `/etc/nginx/sites-enabled/` | Nginx 站点配置 |

## 2. 首次部署（只做一次）

### 2.1 系统初始化

```bash
cd /opt
sudo mkdir -p douxing && sudo chown "$USER:$USER" douxing
git clone git@gitee.com:tyxgo/douxing.git douxing
cd douxing

# Debian 12（推荐）
sudo bash scripts/setup-debian12.sh
# 重新 SSH 登录（docker 组生效）

# 其它系统
# sudo bash scripts/setup-ubuntu22.sh
# sudo bash scripts/setup-opencloudos9.sh
```

### 2.2 环境变量

```bash
cp deploy/env.production.example .env
nano .env   # 改密码、域名、JWT_SECRET、WEBHOOK_SECRET 等
```

Webhook 相关（push 自动发版）：

```bash
WEBHOOK_SECRET=随机长密码
WEBHOOK_DEPLOY_MODE=auto
WEBHOOK_DEPLOY_ALLOW=server,pc,web
WEBHOOK_DEPLOY_BRANCHES=main,master
PC_NGINX_DOMAIN=pc.yxtao.site
WEB_NGINX_DOMAIN=web.yxtao.site
STATIC_ROOT=/opt/douxing/static
SERVER_RUNTIME=tsx
```

### 2.3 后端 + Docker

```bash
pnpm install --frozen-lockfile --prod=false
pnpm deploy:server
curl -s http://127.0.0.1:3000/api/health
```

低内存（2G）若 tsc 卡住：

```bash
pnpm deploy:server --skip-docker --use-tsx
```

### 2.4 Nginx + HTTPS（各站点一次）

```bash
# API
sudo bash scripts/install-nginx-certbot.sh api.yxtao.site 你的邮箱@example.com

# PC 用户端（构建 + Nginx + HTTPS）
sudo bash scripts/deploy-pc-site.sh pc.yxtao.site --certbot

# Web 管理端
sudo bash scripts/deploy-web-site.sh web.yxtao.site --certbot

# 或 PC + Web 一起
sudo bash scripts/deploy-static-sites.sh --certbot
```

仅改 Nginx、不重新构建：

```bash
sudo bash scripts/install-nginx-pc.sh pc.yxtao.site --certbot
sudo bash scripts/install-nginx-web.sh web.yxtao.site --certbot
```

已有 SSL 证书：

```bash
sudo bash scripts/install-nginx-ssl.sh api.yxtao.site /path/fullchain.pem /path/privkey.pem
```

### 2.5 Webhook 自动发版服务

```bash
sudo bash scripts/install-webhook-service.sh --nginx-domain hooks.yxtao.site
# 或在 api / hooks 站点 include snippets/douxing-webhook.conf

sudo systemctl enable douxing-webhook
sudo systemctl restart douxing-webhook
curl -s http://127.0.0.1:9090/health
```

Gitee 仓库 → WebHooks → Push → `https://hooks.yxtao.site/hooks/douxing-deploy`（密码 = `WEBHOOK_SECRET`）

### 2.6 PM2 开机自启

```bash
pm2 startup
pm2 save
```

## 3. 日常发版（推荐：无需 SSH）

```bash
# 本地
pnpm build:ci                    # 可选自检
git commit -m "feat(web): xxx [deploy:web]"
git push origin main             # 触发 Webhook
```

查看服务器发版日志（需 SSH 时）：

```bash
tail -f /opt/douxing/logs/webhook-deploy.log
sudo journalctl -u douxing-webhook -f
```

### 3.1 按 package 自动发什么（`WEBHOOK_DEPLOY_MODE=auto`）

| 变更路径 | 发版目标 |
|----------|----------|
| `packages/server/` | server |
| `packages/pc/` | pc |
| `packages/web/` | web |
| `packages/shared/` | server + pc + web |
| `pnpm-lock.yaml` / `deploy/` | 全部 |
| 仅 `docs/` | 跳过 |

提交信息强制指定：`[deploy:web]`、`[deploy:server]`、`[deploy:all]`

## 4. 手动发版（SSH 到服务器）

### 4.1 统一发版（pnpm）

```bash
cd /opt/douxing
git pull origin main
pnpm install --frozen-lockfile --prod=false

# 全量（server + pc + web）
pnpm deploy:release -- --target=server,pc,web --skip-docker

# 仅后端
pnpm deploy:server --skip-docker
pnpm deploy:server --skip-docker --use-tsx    # 低内存
pnpm deploy:server --skip-docker --skip-build # 仅重启 PM2

# 仅 PC / Web 静态
pnpm deploy:release -- --target=pc --skip-docker
pnpm deploy:release -- --target=web --skip-docker
pnpm deploy:pc
```

### 4.2 Shell 一键脚本

```bash
bash scripts/gitee-webhook-deploy.sh          # 同 Webhook 流程（手动触发）
bash scripts/deploy-pc-site.sh pc.yxtao.site --certbot
bash scripts/deploy-web-site.sh web.yxtao.site --certbot
bash scripts/deploy-static-sites.sh --certbot
bash scripts/ci-build.sh                      # 与 CI 相同构建校验
```

### 4.3 检测本次会发哪些包

```bash
WEBHOOK_BEFORE=旧sha WEBHOOK_AFTER=新sha node scripts/detect-deploy-targets.mjs
pnpm detect:deploy-targets
```

## 5. Nginx 运维

```bash
# 检查配置
sudo nginx -t

# 重载（改配置后）
sudo systemctl reload nginx

# 查看已启用站点
ls -la /etc/nginx/sites-enabled/
grep -rn "server_name" /etc/nginx/sites-enabled/

# 排查重复域名警告
grep -r "yxtao.site" /etc/nginx/sites-enabled/

# Webhook 反代自检
bash scripts/verify-webhook-nginx.sh api.yxtao.site
```

| 脚本 | 作用 |
|------|------|
| `sudo bash scripts/install-nginx-conf.sh [域名]` | API HTTP 反代 |
| `sudo bash scripts/install-nginx-certbot.sh [域名] [邮箱]` | Certbot 申请 HTTPS |
| `sudo bash scripts/install-nginx-ssl.sh [域名] [证书] [私钥]` | 已有证书 HTTPS |
| `sudo bash scripts/install-nginx-pc.sh [域名] [--certbot]` | PC 静态站 |
| `sudo bash scripts/install-nginx-web.sh [域名] [--certbot]` | Web 管理端 |

生成的配置在 `deploy/nginx/douxing-*.conf`（**不入 Git**），生效副本在 `/etc/nginx/sites-available/`。

## 6. 后端 / Docker / 数据库

```bash
# 健康检查
curl -s http://127.0.0.1:3000/api/health
curl -s https://api.yxtao.site/api/health

# PM2
pm2 list
pm2 logs douxing-api
pm2 restart douxing-api
pm2 save

# Docker（MySQL + Redis）
docker ps
docker compose -f deploy/docker-compose.prod.yml up -d
docker compose -f deploy/docker-compose.prod.yml logs -f mysql

# 数据库迁移
pnpm db:migrate
pnpm db:seed          # 谨慎：生产一般不需要重复 seed

# Agent / 景点库（按需）
pnpm --filter @douxing/server agent:intent-cases       # 追问意图路由 10 条用例
pnpm --filter @douxing/server agent:branch-cases       # 四类分支用例
pnpm --filter @douxing/server agent:e2e-cases          # 局部修改 E2E
pnpm --filter @douxing/server agent:equivalence-cases  # 管道 vs Agent 等价率（--fast 跳过 Enricher）
pnpm --filter @douxing/server agent:m2-cases           # M2 Step 12～14 本地断言
pnpm --filter @douxing/server agent:m2-accept          # M2 一键验收（Step 15）
pnpm --filter @douxing/server h9:m3-accept               # M3 H9+ 数据质量验收
pnpm --filter @douxing/server pet:adopt-cases          # H3-a 领养 API 用例
pnpm --filter @douxing/server pet:memory-analyze-cases # H3-c 记忆墙/analyze 用例
pnpm --filter @douxing/server plan-pet-focus:cases       # 规划页宠物 Focus UI 用例
pnpm --filter @douxing/server h3:m4-accept               # M4 H3 + C7-c 一键验收
pnpm --filter @douxing/server replan-segment:cases       # M5 Step 31 H8 replan_segment
pnpm --filter @douxing/server h8:transit-agent-cases     # M5 Step 32 transit_agent + 行中 UI
pnpm --filter @douxing/server h7:missed-poi-cases        # M5 Step 33 H7 错过景点补救
pnpm --filter @douxing/server h3-d:in-trip-cases         # M5 Step 34 H3-d 行中宠物
pnpm --filter @douxing/server h5:m5-accept               # M5 一键验收（Step 31～34）
pnpm ml:generate-dataset                                 # I2 生成训练数据
pnpm ml:validate-dataset -- --split                      # I2 校验并划分 train/val
pnpm ml:upload-dataset                                   # I2 Step 35 上传 OSS + PAI manifest
pnpm --filter @douxing/server i2:pai-lora-cases          # I2 Step 35 本地验收
pnpm --filter @douxing/server langfuse:smoke         # Langfuse 观测冒烟（需 LANGFUSE_* KEY）
pnpm --filter @douxing/server sync:amap-pois           # 高德 POI 批量同步

# MySQL 密码与 .env 不一致时
pnpm fix:mysql-password

# MySQL 备份
docker exec douxing-mysql mysqldump -u root -p"$MYSQL_ROOT_PASSWORD" douxing > backup.sql
```

## 7. 诊断与排错

```bash
pnpm diagnose:server
# 或
bash scripts/diagnose-server.sh

# 低内存加 swap（缓解 tsc 卡住）
sudo bash scripts/add-swap.sh 2

# 发版日志
tail -100 /opt/douxing/logs/webhook-deploy.log

# Webhook 服务
sudo systemctl status douxing-webhook
sudo journalctl -u douxing-webhook -n 50

# 找 node 路径（Webhook 203/EXEC）
which node
```

| 现象 | 命令/处理 |
|------|-----------|
| API 无响应 | `pm2 logs douxing-api` · `pnpm diagnose:server` |
| 构建 tsx 找不到 | `pnpm install --frozen-lockfile --prod=false` |
| lockfile 过期 | 本地更新 `pnpm-lock.yaml` 后 push |
| Nginx 404 | `sudo nginx -t` · 检查 `sites-enabled` |
| Webhook 401 | 核对 Gitee 密码与 `WEBHOOK_SECRET` |
| tsc 卡住 | `pnpm deploy:server --skip-docker --use-tsx` |
| git 误 add | `git restore --staged .` · **不要 commit** |

## 8. Git（服务器上）

```bash
# ✅ 允许
git pull origin main
git status
git log -1 --oneline

# ❌ 禁止
git add .
git commit
git push

# 误 add 后取消暂存
git restore --staged .
git rm --cached static/ -r          # 若 static 被跟踪
git update-index --assume-unchanged packages/pc/tsconfig.tsbuildinfo   # 临时
```

## 10. 防火墙 / DNS

```bash
# UFW（若启用）
sudo ufw allow 22
sudo ufw allow 80
sudo ufw allow 443
sudo ufw status
```

腾讯云轻量控制台 → 防火墙：放行 **22、80、443**。

DNS A 记录：`api` / `pc` / `web` / `hooks` → 服务器公网 IP。
